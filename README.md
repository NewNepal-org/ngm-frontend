# NGM Frontend

> ## ⚠️ This repository is archived
>
> The NGM frontend has been **superseded by the consolidated Jawafdehi platform**. Nepal's judicial data — collected by Nepal Government Modernization (NGM) — is now served through the unified Jawafdehi web application at [jawafdehi.org](https://jawafdehi.org), and the NGM backend now lives as the `courts` Django app in the consolidated Jawafdehi platform monorepo. This repository is kept for history only — it is no longer maintained and receives no further changes.

This was the standalone React + TypeScript + Vite frontend for browsing the court cases, hearing records, and legal proceedings collected by [NGM](https://github.com/Jawafdehi/ngm). Its functionality has moved into the main Jawafdehi web app.
